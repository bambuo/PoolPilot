# 标的图标来源

- `web/public/symbol-icons/`：nvstly/icons 全库的 6,346 个图标，由 250px PNG 经 VTracer
  描摹为 SVG（6,340 个）；描摹失败的 6 个保留 PNG。原仓库只有位图，因此这是矢量化近似，
  不是原始矢量源。图标放在 `public`，运行时按标的代码取图，不打进 JS 包。
  该仓库**没有声明 LICENSE**；按项目所有者要求全量引入，对外分发前需自行确认授权。
- `simple/*.svg`：来自 [Simple Icons](https://github.com/simple-icons/simple-icons)（CC0 1.0），
  补 nvstly 缺失的 SPCX、SPACEX、ANTH。

图标是各自公司的商标，仅用于在持仓表中标识对应标的；商标权归各公司所有。
